# 2D 深阱散射问题的理论推导：强形式 PINN 为何失效，以及可解的表述形式

（2026-11-05，全部推导可由仓库代码与 `results/server_2d/` 存档数据复核；所有数值为实算，无拟合。）

## 1. 模型与散射波表述

冻结 OH 键模型（r ≡ r_e）在 Jacobi 坐标 (R, γ) 下的约化波函数 χ = R·ψ 满足

    H χ = E χ,   H = -B_R ∂²_R + (B_R/R² + B_r/r_e²) ĵ² + V(r_e, R, γ),

其中 B_R = ℏ²/2µ_R ≈ 30 cm⁻¹·Å²，E = E_c - D_e（渐势 V(R→∞) = -D_e）。时间约定
e^{+iEt} 下，入射波（朝 -R 传播）为 e^{+iKR}，K = √(E_c/B_R)。

**散射波表述**：令 χ = e^{+iKR} + χ_sc。因为

    (H - E) e^{+iKR} = (E_c + V - E_tot) e^{+iKR} = (V + D_e) e^{+iKR},

只在相互作用区（V ≠ -D_e）非零，所以 χ_sc 满足**非齐次**问题

    (H + CAP - E) χ_sc = -(V + D_e) e^{+iKR},      (1a)
    χ_sc(R_lo) = χ_sc(R_hi) = 0 （CAP 激活时）,     (1b)

CAP 吸收势 -iη·s²（s = max(0,(R-R_start)/w)）吸收出射通量，消除深阱盒共振
（无 CAP 时内部解对网格/盒尺寸的 L2 差达 128–156%，见 `results/server_2d/convergence_2d.json`）。

**要点**：入射波被解析地提出，源项 (V+D_e)e^{iKR} 是已知函数。未知量只剩散射波。

## 2. 强形式残差训练的失效分析（为什么 122% 是必然）

强形式 PINN 最小化标度化残差

    L = mean_i |(H+CAP-E)χ_θ(x_i) + (V+D_e)e^{iKR_i}|² / S²,   S = |E_tot| + B_R K².

**误差—残差换算**。设残差水平为 ε（标度化）。方程中最大的算符是 -B_R ∂²_R 与
(V-E)：对局部长度尺度 ℓ 的扰动 δχ，有 |B_R ∂²_R δχ| ~ B_R δχ/ℓ²，而在振荡区
ℓ ~ 波长/2π ≈ 1/K，故

    δχ ≳ ε·S / (B_R K²) = ε·S/E_c.                    (2)

实测（本仓库，服务器 A100 实算）：残差在 ε ≈ 7×10⁻² 处平台，与网络宽度、
Fourier 特征数、训练步数（3000→10000）无关。代入 S/E_c ≈ 4.1×10⁴/200 ≈ 205 得

    δχ ≳ 0.07 × 205 ≈ 14 → O(1) 解误差。

这**定量解释**了观测到的 L2 = 122% (E_c=200)：残差平台不是优化失败，
而是强形式泛函的条件数问题——残差每降低一个数量级需要解精度提高
E_c/S 个数量级的反向放大。要把 δχ 压到 1%，需要 ε ~ 5×10⁻⁵，即残差再降
三个数量级；Adam/L-BFGS 在 10⁴ 步内做不到（梯度在不同尺度区域的
范数相差 (KΔR)² ~ 10² 倍，病态 conditioning）。

**结论**：失效是结构性的（泛函形式），不是容量问题（4×128、64 Fourier、
10000 步的升级配置残差不变——`results/server_2d/pinn_upsize.log`）。

## 3. 弱形式 / 线性配置：为什么它可解

把解限制在固定基函数张成的线性空间 span{φ_n}，最小化加权残差泛函

    min_c Σ_i w_i |Σ_n c_n (L φ_n)(x_i) + src(x_i)|²,   L = H + CAP - E,   (3)

这是**线性**最小二乘。它有两个结构优势：

1. **无优化平台**：目标函数是 c 的二次型，全局极小由法方程一次求解给出；
2. **准最优性（Céa 型论证）**：式 (3) 的加权残差最小化解 c* 满足

   ‖L(χ_{c*} - χ_exact)‖_{L²_w} ≤ ‖(L φ_n) 的 Gram 谱条件‖ ·
   inf_{c} ‖L(χ_c - χ_exact)‖，

   即误差由**最佳逼近误差**控制（基空间对真解的逼近能力），而不是被
   二阶导数的逆放大控制。这正是 1D Morse 散射（载波+交叉验证线性 LS，
   0.67–0.95%）与 6D H₂+H₂（固定 sin/cos 基线性配置，均值 0.53%）成功的共同原因。

**基函数选择（随机 Fourier 特征，ELM 式物理信息配置）**：

    φ_n(R, γ) = w(R) · cos(w_R,n R̂ + w_γ,n γ̂ + b_n),   w(R) = (R-R_lo)(R_hi-R),

w ~ N(0, diag(σ_R², σ_γ²))，b ~ U[0, 2π)。包络 w(R) 硬性满足两端 Dirichlet (1b)。
Lφ_n 有解析表达式（cos 的二阶导与角向 ĵ² 作用均为初等函数）：

    ∂²_R φ = -(2w_R/ΔR)² φ,   ĵ² φ = w_γ² φ + w_γ cotγ · sin(w·x + b)  修正项,

其中 R̂ = 2(R-R_lo)/(R_hi-R_lo)-1。频率 σ_R 按需覆盖解的振荡：
波长 λ = 2π/K ≈ 1.2–1.9 Å 对应归一化频率 2π/λ̂ ≈ 15–25，故取 σ_R ∈ {8, 20}
混合尺度（包络 + 振荡），σ_γ ≈ 6（角向变化缓慢）。

**交叉验证岭回归与诚实验收**：节点随机分为拟合/验证两层（80/20），
λ 在 logspace(-14,-1) 扫描，选验证残差最小者；最终误差只对 FD 参考解
报告，选择过程不接触参考解（同 1D `ScatteringPINN1D` 的验收协议）。

## 4. 多通道渐近展开与系数提取

在 R > R_as ≈ 4 Å（角向势被 g(r)=e^{-b_g(r-r_e)²} 指数抑制，V ≈ -D_e 各向同性），
方程解耦为 ĵ² 的本征通道。取 DVR 节点角向矩阵 ĵ² 的本征对 (ε_j, Φ_j(γ))，径向波数为

    k_j = √((E_c - B_rot·ε_j)/B_R)，开通道实，闭通道虚 (k_j = iκ_j)。   (4)

出射渐近解为

    χ_sc(R > R_as, γ) = Σ_{j 开} c_j H²_{ν_j}(k_j R) Φ_j(γ) + Σ_{j 闭} c_j K_{ν_j}(κ_j R) Φ_j(γ),

其中 H² 为第二类 Hankel 函数（出射柱面波 e^{-i(kR - νπ/2 - π/4)}，时间约定
e^{+iEt}），闭通道用衰减的修正 Bessel K。系数向量 c ∈ ℂ^{n_ch} 就是该能量的
反应矩阵信息，由神经网络解在匹配区 R ∈ [R_as, R_cap) 的最小二乘拟合读出：

    min_c Σ_{x ∈ 匹配区} w(x) |χ_θ(x) - Σ_j c_j F_j(k_j R) Φ_j(γ)|².    (5)

提取系数的物理意义不依赖拟合：F_j 是渐近方程的精确解（零可调参数），
c_j 是投影系数。开放通道通量守恒要求 Σ|c_j|² k_j/k_0 ≤ 1（CAP 的微小吸收
使其略小于 1），可作物理自检。

1. **式 (2) 的误差—残差换算被双向验证**：强形式与线性配置遵循同一规律，

2. **线性配置的瓶颈是张成空间的逼近能力，不是优化**：阱底局域波数
   k ≈ √((E_tot - V_min)/B_R) ≈ 36 Å⁻¹（波长 0.17 Å），σ_R=120 的随机特征

   且节点同步加密——随机基比张量积基（FD/DVR）多浪费一个维度量级的自由度，
   这正是 Céa 准最优性中"最佳逼近误差"项的代价。
3. **诚实结论**：对此深阱 2D 散射问题，强形式 PINN 与随机特征线性配置均不可用。
   可用的表征必须把 e^{ik(R,γ)R} 振荡吸收进载波——即 2D eikonal/Langer 载波
   + 光滑神经修正（1D 已验证、0.67–0.95% 精度的方法论推广）。已记录为下一步工作。

## 7. 二维载波理论：绝热通道 eikonal + 均匀 Langer-Airy 构造

§6 的结论是：任何不吸收 e^{ik(R,γ)R} 振荡的表征都无法通过残差判据。本节推导
载波构造，把振荡放进**解析的**通道 Langer-Airy 函数里，使剩下的修正场是
光滑的（低波数），从而恢复到 §3 中 Céa 论证有效的情境。

### 7.1 主符号与 eikonal 方程

令 χ(R,γ) 为约化波函数（χ = Rψ），

    H = -B_R ∂²_R + C(R) ĵ² + V(R,γ),    C(R) = B_R/R² + B_r/r_e²,   (6)

其中 ĵ² = -(∂²_γ + cotγ ∂_γ)。写 WKB 形式 χ = A e^{iS}（S 单位 cm⁻¹·Å）。算符的
主符号（最高阶导数）作用给出

    H[A e^{iS}] ≈ [B_R (∂_R S)² + C(R)(∂_γ S)² + V - E] A e^{iS} + O(∂²S, ∂S ∂A).

Eikonal（Hamilton-Jacobi）方程：

    B_R (∂_R S)² + C(R) (∂_γ S)² = E - V(R,γ).                    (7)

取径向主导近似 ∂_γ S = 0（角向结构交由绝热通道函数承担），得到**通道 eikonal**

    ∂_R S_j = k_j(R) = √((E - V_j(R)) / B_R),                      (8)

其中 V_j(R) 是通道平均势。下一步给出其第一性原理定义。

### 7.2 绝热通道基（anisotropy → 通道曲线）

固定 R，对角化角向算符

    H_γ(R) = C(R) ĵ² + V(R,γ)  →   H_γ(R) Φ_j(R,γ) = ε_j(R) Φ_j(R,γ).   (9)

在 Legendre-DVR 表示下，H_γ(R) 是 n_gamma × n_gamma 实对称矩阵
C(R)·J² + diag(V(R,γ_g))，一次 eigh 给出 ε_j(R) 与 Φ_j(R,γ_g)；跨 R 用最大
重叠 |⟨Φ_j(R_i),Φ_j(R_{i+1})⟩| 跟踪通道连续性（避免本征值排序造成的伪交叉）。
ε_j(R) 即**绝热通道能量曲线**，V_j(R) = ε_j(R) 就是 (8) 中的通道势。转折点
R_c,j 由 ε_j(R_c,j) = E 定义。

### 7.3 通道 Langer-Airy 载波（无零点、渐近纯入射/出射）

对每个通道 j，定义通道作用量

    S_j(R) = sign(R-R_c,j) ∫_{R_c,j}^{R} k_j(R') dR',               (10)
    ζ_j(R) = sign(R-R_c,j) (3|S_j(R)|/2)^{2/3},                    (11)

振幅因子与 1D 完全一致：

    A_j(R) = |ζ_j / (B_R k_j²)|^{1/4},   转折点附近 → (B_R/|V_j'(R_c)|)^{1/6},  (12)

载波基

    U^±_j(R) = A_j(R)[ ±i Ai(-ζ_j) + Bi(-ζ_j) ].                   (13)

Ai、Bi 线性组合在实 ζ 上无零点（Airy 零点只落在负实轴），因此 U^± 不产生
伪节点；其渐近行为（ζ→+∞）

    U^±_j ~ π^{-1/2} ζ_j^{-1/4} e^{±i(S_j + π/4)}   (ζ_j → +∞),

即 ±i 组合分别给出**纯入射**与**纯出射**分支——这正是把 e^{±ik_j(R)R} 振荡
解析地装进基函数的关键。ζ<0（禁戒侧）时 Bi/ Ai 的自然指数衰减保证壁区
不冻结。

### 7.4 全解 Ansatz 与修正方程

    χ_sc ≈ Σ_{j∈S} Σ_{σ∈{+,-}} c^σ_j U^σ_j(R) Φ_j(R,γ) + (修正特征),   (14)

S 取载体通道集合（开放通道 + 浅闭合通道，深闭合通道在 R_hi 处 < e^{-40} 可忽略）。

把 (14) 代入 L = H - E (含 CAP)，逐项分析**残差的结构**：

1. **载波项**：由 (9)-(13)，每个通道满足通道径向方程到 O(∂²_R Φ_j, ∂_R Φ_j)，
   所以 L[U^σ_j Φ_j] = [L_rad,j U^σ_j] Φ_j + 2∂_R U^σ_j ∂_R Φ_j + U^σ_j ∂²_R Φ_j。
   L_rad,j U^σ_j 由构造为零（Langer 变换吸收了 V_j 与 k_j 的全部径向振荡），
   故载波残差只剩下**绝热耦合项** ∂_R Φ_j ~ O(1/R²) 与 ∂²_R Φ_j，
   即慢变、局域的源项。
2. **修正项**：m^σ_j(R) 为光滑包络，L[m U Φ] 的主部是 -B_R m'' U Φ，
   而 U 振荡因子使该项变成 m''·e^{iS_j}；因此修正场的有效波数是
   **包络波数** m''/m ~ (V_j'/k_j)² ~ O(1 Å⁻¹)，比 k_j ~ 36 Å⁻¹ 小 1.5 个量级。

**定量结论**：载波把解的"高频相位"完全解析化，需要被数值表示的部分只剩
低波数修正场；§3 的 Céa 准最优性因此重新可用——低频谱空间（少量 Fourier
特征 + 多项式包络）即可达到高精度，而不会像 §6 那样要求 M ≳ 4×10⁴。

### 7.5 线性化与诚实验收（与 1D 方法论一致）

系数 c^σ_j 与修正特征权重都是线性的，一次交叉验证岭回归求解：

    min_c ‖W(L_basis c + src)‖² + λ‖c‖²,    λ 由验证残差选取.      (15)

其中 L_basis 是同一离散算符（4 阶 FD × Legendre-DVR，与参考解共享）作用在基上
的矩阵；src = -(V+D_e)e^{iKR} 为入射源。验收协议同 §5：λ 的选择只依赖 PDE
验证残差；若加入修正特征后验证残差无改善，则**回退到纯载波**并如实记录
（1D 中同一协议曾诚实拒绝神经修正，fallback=True）。

1. **载波单独不可用**（L2 = 4.06 / 11.0）：载波列在 LS 中的残差与算子同量级，

   * 通道径向残差 ||-B_R U'' + (ε_j - E)U|| / (S‖U‖) = **10%–16%**：400 点网格

     这超出了"慢变"假设；
   * Bi 支在禁戒区指数增长，若无壁窗约束会主导 LS（已加 `wall_window`，
     但仅能抑制不能消除）。
2. **修正特征确实有效但不能救场**：验证残差从 0.98 降到 ~0.48（约减半），
   L2 从 4.06/11.0 降到 0.51/0.76（相对强形式 PINN 的 1.22/1.56 改善 2×），
   但离参考不确定度（1.5%/0.55%）仍差 1.5–2 个量级。即：
   **光滑修正吸收的是"载波没解准"+源项拟合的残差，而不是理论预期的
   低波数修正场**——因此 §7 的 Céa 优势没有兑现。
3. **可复现的下一步**（按优先序）：
   a. 在载波构造时使用更细的 R 网格（如 1600 点）计算 U±，再插值到 LS 网格，
      或在 LS 中使用 4 阶差分无法分辨的高波数时改用解析导数
      （Airy 的 ODE Ai''=z·Ai 可给二阶导的闭式表达式）；
   b. 改用**绝热基的规范固定**：在通道函数中同时计入 Berry 型几何相位项
      ∂_R → ∂_R + iA（消除 |⟨Φ_j|∂_R|Φ_k⟩| 的组内耦合）；
   c. 若 a/b 仍不够，则改用 close-coupling/Johnson log-derivative 的
      CAP 参考路线（§1 已知的成熟方案，作为数值答案的金标准），
      载波仅用于加速 PINN 的预训练而非独立求解器。

## 9. 离散一致载波：为什么解析载波在 400 点网格上失效，以及离散精确的通道解

§8 诊断出的第一个大误差源是"载波通道径向残差 10–16%"。本节把这一现象推导清楚，
并给出与参考解**离散一致**的载波构造（这是本节的代码实现）。

### 9.1 有限差分的离散色散

离散算符（与参考解相同，4 阶：

    (D² u)_i = (-u_{i-2} + 16u_{i-1} - 30u_i + 16u_{i+1} - u_{i+2})/(12h²).      (16)

对纯平面波 u_i = e^{iq i h}，代入得

    D² u = κ²(q) u,   κ²(q) = [30 - 32cos(qh) + 2cos(2qh)] / (12h²).        (17)

而连续谱波数满足 κ_cont² = q²。用 (qh) 展开：cos(qh) = 1 - x²/2 + x⁴/24 - x⁶/720,
cos(2qh) = 1 - 2x² + (2/3)x⁴ - (4/45)x⁶ (x = qh)：

    κ²(q) h² = x² - x⁶/90 + O(x⁸)  ⇒  κ(q) = q (1 - x⁴/180 + ...).         (18)

即离散波数与真实波数有 **O((qh)⁴) 的相对偏差**。阱内 q ≈ k ≈ 25–36 Å⁻¹、h ≈ 0.029 Å，
故 qh ≈ 0.72–1.03，(qh)⁴/180 ≈ 1.5×10⁻³–6×10⁻³。沿 2–3 Å 的阱区累积相位误差

    ΔS ≈ ∫ (κ_disp - k) dR ≈ 0.6–1.8 rad                                    (19)

——**足够破坏解析载波与离散参考解之间的相干**。这正是 §8 中"载波解析正确、
但在该网格上无法被离散差分识别"的定量含义：解析 Langer-Airy 满足连续方程，
而 LS 用的算符是 (16)。两者的差是 O((qh)⁴) × 积累长度，不是可忽略的截断噪声，
而是 ~1 rad 的相位失配，直接表现为列残差 10–16%。

**结论**：与参考解共享离散算符的求解器，其基函数应当是**离散算符的（近）精确
解**，而不是连续算符的解析解。

### 9.2 离散色散修正的 WKB：如何在 4 阶算符下构造一致载波

自然想法是直接求 4 阶离散方程的齐次解。但 (16) 的 5 点模板给出的是
**五项递推**

    u_{i+2} = -u_{i-2} + 16u_{i-1} - 30u_i + 16u_{i+1}
              + (12 h² / B_R) (E - ε_{j,i}) u_i,                        (20)

它需要 4 个初值 (u_0..u_3)，而连续二阶方程只有 2 个积分常数；多余的两个
自由度在边界处被截断模板（rows i=0,1）约束，因此"从一端直接递推"的
齐次解并不唯一确定——直接实现会给出一族在网格上一阶不封闭的解，
数值上也极不稳定（禁戒区增长解会迅速淹没）。这不是本问题的正确路线。

正确的路线是**离散色散修正**。WKB 只要求局部满足离散色散关系 (17)：

    [30 - 32cos(qh) + 2cos(2qh)] / (12h²) = k_j²(R) ≡ (E - ε_j(R))/B_R.   (21)

f(x) ≡ 30 - 32cos x + 2cos 2x 在 (0,π) 上单调（f'(x)=4 sin x (8-cos x) > 0），
故对每个 R 有唯一解 q_j(R) ∈ (0, π/h)。用

    S^{disc}_j(R) = sign(R-R_c,j) ∫_{R_c,j}^{R} q_j(R') dR'              (22)

替代 (10) 中的连续作用量，其余构造（ζ、振幅、Airy 组合）不变。由
(18) 的展开，q 与连续 k 的差为 O(k (kh)⁴/180)，代入 (22) 后**相位失配
从 §9.1 的 0.6–1.8 rad 降到 O(k L (kh)⁶)** ≈ 10⁻² rad 量级，即与
4 阶差分本身的截断误差同阶。禁戒区 (k²<0) 使用连续衰减常数
κ = sqrt(|k²|)（指数衰减，色散修正对振幅影响为二阶小量）。

因此在实现上：
  * 允许区：g_i = q_j(R_i)·h（由 (21) 的二分求根给出），
  * 禁戒区：g_i = sqrt(|k_j²|)·h，
  * 作用量 S 用梯形累积，ζ/amp/Airy 与 §7.3 完全相同。

### 9.3 关于 Berry 规范的一个澄清（真实基下对角联络恒为零）

绝热通道函数 Φ_j(R,·) 随 R 转动时可能给出对角联络
A_jj = ⟨Φ_j|∂_R Φ_j⟩ 与 Berry 相位 e^{i∫A_jj dR}。但对**实**本征函数

    A_jj = ½ ∂_R ⟨Φ_j|Φ_j⟩ = 0                                       (24)

恒成立（归一化不变），因此在本问题的实对称 DVR 表示下对角 Berry 相位
严格为零，把它乘进载波是空的。§7.3 的符号规范（首节点分量为正 + §7.2 的
最优匹配）已经固定了所有可规范化的部分，载波列残差中真正剩下的只有
**非对角耦合** A_jk（j≠k，即非绝热跃迁）。这一点在此前把它写成"待修
的正项"是错误的，本实现不再引入 Berry 因子；若将来使用复本征基
（如加入磁场的体系），(24) 才会失效并需要重新推导。


## 10. 离散色散修正的实测结果与残差归属（2026-11-26，服务器/本地实算）

把 (21) 的离散色散相位接入载波（`AdiabaticCarrier2D._q_disp`，二分求根 80 步，
误差 <1e-10）后，逐列残差

    r_j = ||A Ψ_j|| / (||Ψ_j|| · |E_tot|)                             (25)

的实测结果（E_c=200，400×60 网格，8 个绝热通道）：

| 通道类型 | 连续相位 (10) | 离散色散相位 (22) |
|---|---|---|
| 开放/近开通道 j=0,1,2 | 0.171 / 0.157 / 0.172 | 0.171 / 0.157 / 0.172 |
| 半闭通道 j=4,7 | 0.719 / 0.571 | 0.719 / 0.571 |
| 深闭通道 j=9,11 | 0.914 / 1.339 | 0.914 / 1.339 |

**关键发现（诚实负结果，与前文预测相反）**：离散色散修正**没有改变任何列残差**。
即 §9.1 估计的相位失配（(qh)⁴ 累积 ~0.6–1.8 rad）在当前分辨率下并**不是**
载波残差的主导项；主导项是

1. **绝热耦合** 2∂_R U ∂_R Φ_j + U ∂²_R Φ_j（§8 已量化 7–21%，壁区为主）；
2. **深闭通道的构造质量**：j≥4 的列残差 0.57–1.34，说明这些通道的
   Langer 转折点/衰减解在网格上明显不满足离散方程（它们是"全禁戒"或
   仅在很窄区间允许，ζ 与 amp 的数值构造误差被放大）。

**另一个结构性事实**：载波列近似满足**齐次**离散方程，而未知量满足
**非齐次**方程 L χ_sc = src，且 ‖src‖ 与算子同阶。因此任何齐次列的线性组合
在 LS 中都无法拟合源项——这正是"纯载波 val_res ≈ 0.98–0.99"的成因
（载波只提供传播结构，不提供源的响应）。加入 300 个非齐次（光滑）特征
后 val_res 降到 ~0.48、L2 降到 0.51/0.76（§8 表），说明当前框架里**真正
在干活的是修正特征，而不是载波**。

**由此修正的路线判断**（写进下阶段计划）：
  a. 载波基需要包含"源的响应"：把散射波写成齐次载波 + 特定积分
     （源项的 Green 函数/WKB 积分），基函数才能在同一 LS 中同时拟合
     L = 0 与 L = src 两个分量；
  b. 或者采用真正的**耦合通道（close-coupling）基**：把 j≠k 耦合
     A_jk 直接放进基函数（解耦后的载波组合），使列残差互相抵消；
  c. 参考金标准仍建议 Johnson log-derivative + CAP（§1、§8 已记录）。
